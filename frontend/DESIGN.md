# Domainry Agent 视觉约定

## 产品与依据

面向日常知识工作的对话工作台，核心任务是连续讨论、查阅文档依据、管理个人待办与成果。现有 React / shadcn / AI Elements 界面已经具备这些能力。本次依据当前 App、SessionApp、全局 CSS 和本地页面截图调整表现层；保留已有 API、会话状态、授权默认值、确认与恢复流程。

## 设计方向

延续 Domainry 的 `d.` 标识与绿色主色，采用纸白内容区、浅灰导航、墨色正文、松绿色主操作。通过清晰的留白和文字层级呈现轻量工作台；不使用大面积渐变、装饰图或玻璃效果。欢迎区用四个有说明的任务入口，消息区以阅读为先。

## 共同规则

- 语义颜色：背景 `#fdfdfb`，侧栏 `#f5f6f4`，正文 `#25332e`，次级文字 `#68736d`，主操作 `#285c4d`，主操作浅底 `#eaf1ed`，边框 `#e2e6e1`，危险 `#b13e32`。警告使用独立琥珀色，并始终附文字。
- 字体使用系统中西文字体，不加载外部字体。正文 15px / 1.85，常规操作 13–14px，说明 12px，页面标题 18px，欢迎标题 34px。小字不承担核心操作说明。
- 基础间距 4px；常用 8 / 12 / 16 / 24 / 32。输入和按钮圆角 8px，信息卡 12px，主输入区和弹窗 18px。阴影仅用于输入区、浮层、选中导航的轻微抬升。
- 桌面侧栏 256px，内容与输入区域共用 840px 最大宽度。资料和执行记录的表格、长内容在自身容器内滚动。
- 授权选项合并为可展开的「本次操作权限」，摘要持续显示当前范围；完整创建、修改、删除/导出说明保留在选项中。默认勾选状态、草稿存储和后端确认机制不变。
- 窄屏使用已有导航弹窗，四个入口变为两列；保持 16px 输入文字，移动端主要操作至少 40px，允许内容滚动而不挤压输入框。短窗口减少欢迎区留白。
- 焦点使用可见绿色轮廓；状态不只依靠颜色表达；支持 reduced motion。原生表单、弹窗、菜单保留键盘和屏幕阅读器语义。

## 验证范围

检查桌面与移动端的空会话、消息与引用、菜单、授权展开、草稿、新建会话、个人记忆、待办和成果弹窗。使用独立本地合成数据预览验证表现层；真实检索和后端模型执行不属于本次视觉验收。

## 本次验收记录

- 1440 × 900：工作台、带表格的对话、文档引用详情、会话菜单及重命名表单。
- 390 × 844：欢迎入口、消息阅读、导航弹窗、个人记忆、待办新增表单、成果空状态和登录页；页面无横向溢出，长表单在弹窗内滚动。
- 交互：入口填入草稿、授权勾选与摘要同步、Escape 关闭授权选项、菜单打开后表单获得焦点。
- 前端 TypeScript / Vite 构建通过；既有 19 项状态测试通过。真实模型调用与文档检索未在本次视觉验收中重复执行。
