# K07 会话私有附件真实知识服务验收

2026-09-11。实际 Identity / Agent Module / HTTP 处理器 / SQLite 宿主连接真实 Verdent，完成一份私有合成附件的完整生命周期，58.90 秒通过。K07 暂不勾选：上传响应丢失且始终无法观察到远端结果时，仍缺完整上传回执或可证明的幂等恢复契约。

## 索引的归属

普通附件上传只保存原件，显式请求“用于当前会话检索”才通过官方 Connector 提交知识服务。Agent 保存文档映射、授权和远端任务进度；解析、切块及检索索引属于知识服务。原件预览沿用授权下载与浏览器查看器，本批没有恢复 Agent 源文件解析。

## 实际范围与结果

- 使用专用合成验收 KB `kb-1a07a88ed780`，没有上传用户资料，没有修改用户 Web 服务的生产配置。原件为带唯一会话编号的 Markdown；模型使用确定性工具驱动，知识检索与读取实际调用 Verdent。
- 两个真实 Identity 测试账户参与。另一用户即使具备附件动作权限仍不能下载原件；同一用户换会话路径也被拒绝。独立索引权限、核对权限和伪造 ACL / 用户 / 重复版本参数均验证拒绝。
- 唯一一次远端上传成功后，在宿主测试 Transport 中主动丢弃响应。Agent 保留原文档与请求编号，随后观察到远端处理完成并进入 ready，没有重传原件。真实服务使用省略 ACL 或错误 ACL 查询均不可见，正确会话私有 ACL 可读取。
- 会话执行 `attachment_search` → `attachment_read` → 引用回复，使用实际远端片段。撤销读取工具或原件下载权限后，旧内容与引用隐藏；恢复权限后可读。
- 完整关闭并重建宿主，重新登录后原索引请求、核对版本与引用仍可恢复，下载原件字节完全一致。
- 删除父会话后原件接口立即返回 404。真实远端 DELETE 返回 `ok:true`，清理统计为 1 文档、4 行、2 个 S3 对象和 1 个向量；fetch / search 不再返回该文档。SQLite 最终状态为 deleted、原件引用已清空，磁盘原件数量为 0。

独立只读核查保留 `put_started:true`、`put_acknowledged:false`、`index_observed:true`、`delete_acknowledged:true`，明确区分“原上传回执丢失”和“后来已观察到成功”。专用 KB 留空供后续验收复用；合成文档已删除。

## 尚未完成的上传恢复

核对 `kb-builder` 固定提交 `504be6674ee4593ba740d1a409f2927f8bc6b2c6`：上传请求 ID 约束 ACL 受理，但不能代表完整二进制上传事务的回执。重复上传会产生带当前修改时间的元数据对象，并启动带随机后缀的处理任务；原件按内容哈希存储不足以证明整条上传链路可安全重放。删除后的普通文档虽然有防止迟到任务恢复的约束，也不能据此宣布上传完全幂等。源码定位与节选见[上传契约记录](evidence/2026-09-11-k07-upload-protocol/source-contract.json)。
