# C05：共享 Agent 配置与实际执行主体

日期：2026-09-13。接续[计划原回执阅读](testing-2026-09-13-c05-schedule-result-reading.md)。本阶段已完成指定用户使用同一个 Agent 配置、实际执行身份隔离及页面；**C05 尚未整项完成，整表仍为 4／25**。

## 行为与边界

- Agent 配置增加 `owner_user_id`、`shared` 和所有者可见的 `shared_with_user_ids`。所有者可授权同一 Runtime／工作空间中最多 64 个有效用户使用配置；接收者只能发现和使用，不能修改配置，也看不到其他接收者名单。默认 Agent 继续各用户独立。
- 配置写入仍要求 `configure`，共享名单变更另外要求 `share`。当前 Identity 复核实际操作者和目标用户成员状态；使用共享配置时复核配置所有者当前有效性。当前宿主缺少成员核对端口时拒绝共享，不把权限查询故障伪装成完整空目录。
- 委派和运行快照保存 `execution_subject`（Runtime、工作空间、用户）。冻结配置所有者与实际调用者分别记录；任务、工具、数据、确认和会话继续使用实际调用者的当前权限。未新增可由浏览器或模型指定执行身份的参数。
- 同一个共享 Agent 的运行数与并发名额按工作空间内该 Agent ID 汇总；自己的任务、会话、原回执和历史仍按实际执行用户隔离。配置所有者不能因共享配置读取调用者的私有任务。目录只分享汇总负载，匹配历史仍限当前用户。
- 配置和共享授权在同一 ORM 事务写入、重放和撤回，沿用工作空间容量锁。每位用户最多可见 64 个自建或共享配置；接收者目录达到上限时整笔写入回滚。新增宿主迁移 **25 `agent_explicit_use_grants`**，SQLite／Postgres／MySQL 渲染通过，未增加独立迁移账本。
- 接单、恢复和每次实际执行边界仍复核当前配置、共享授权、执行主体及专业权限。撤回共享或更新配置后，旧版本工作停止；队列仍能认领失效配置并记录失败，避免其阻塞其他工作。重启不会重新授予已撤回的共享。
- 已存在的本用户运行快照可以继续核对；缺少执行主体的旧快照不能通过共享配置取得其他用户身份。
- 页面显示共享来源、配置所有者、实际执行用户；所有者可编辑共享名单，接收者没有配置入口。保存只发送写入契约字段，避免将服务端归属、时间戳和定义摘要一起提交。当前名单输入使用用户 ID，服务端核对真实成员；未增加 Identity 成员管理功能。
- Module／HTTP 沿用现有配置与委派接口，SaaS 保留实际操作者、原字段和当前错误；写入时省略共享名单表示保留，显式空数组表示撤回。

## 已验证

- 实际 Identity 双用户、Agent HTTP、SQLite worker：分别建立私有待办，调用共享 Agent；原工具回执及模型输入只含调用者自己的数据，运行记录同时保留配置所有者与执行用户。配置所有者访问对方委派／会话／回执均被拒绝。
- 修改共享需要独立 share 权限；不存在的目标用户被拒绝；接收者不能编辑。执行中分别撤回实际调用者的 todo_list 权限和配置共享，随后模型返回的工具调用均未执行。共享和原回执可重启恢复，撤回状态也可重启保持。
- 真实存储：不同用户同时接入同一 Agent 只获得一个并发名额，两侧看到相同负载；终态历史只属于实际执行用户；跨用户、工作空间、Runtime 读取拒绝；目录上限失败整体回滚。
- 应用：快照不可切换用户／工作空间／Runtime；兼容旧本用户快照，拒绝旧共享快照；成员撤权和成员查询故障分别处理。
- SaaS 实际 HTTP：共享名单、省略与空数组、用户主体、当前归属拒绝及工作空间边界保持。
- 真实 Chrome 双会话：所有者共享已有配置、接收者出现、接收者无配置入口、再次修改真实服务端返回的配置、390px 窄屏、撤回后实时移除与刷新保持。没有页面运行错误。
- 应用、持久化、SDK、能力描述、HTTP Module、remote、server 回归通过；针对新边界的 race 检查通过；前端状态测试及生产构建通过。具体命令、原日志、截图和源码摘要见[阶段证据](evidence/2026-09-13-c05-agent-sharing/commands.md)。构建保留现有大分块提示，未据此改动无关打包配置。

## C05 剩余工作

配置共享没有授予其他人的专业工具权限，也没有自动将其加入某项私有委派。后续仍需实现**具体委派的参与人／角色授权、不同执行主体之间的通信和管理、以各方当前专业权限接单，以及交付和执行阅读的精确共享范围**。需要继续保留真实操作人、任务版本、私有会话／附件隔离与来源权限，不可将配置所有者当作通用执行身份。

本阶段不涉及发布；当前工作区 SDK 增量与 Runtime 已发布模块锁的联合发布检查继续保留，不改写已发布锁来掩盖版本差异。
