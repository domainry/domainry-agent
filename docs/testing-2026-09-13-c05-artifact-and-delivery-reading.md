# C05：Knowledge 成果阅读与交付原回执入口

日期：2026-09-13。 本文保留回执阶段的验证快照；后续完整正文和既有导出入口见[成果资源读取](testing-2026-09-13-c05-delivery-artifacts.md)。延续[报表／分析／账号回执阶段](testing-2026-09-13-c05-report-and-receipts.md)，对应[核心 TODO C05](agent-core-capabilities-todo.md)。本批完成以下增量；C05 尚未完整验收，整体仍为 **4／25**。

## 已实现行为

- 授权交付读取中的 `artifact_create`、`artifact_edit`、`artifact_export` 回执改用 Knowledge 公开 `ArtifactAccess` 核对当前 `artifact_read`，绑定保存的准确 ID／版本。读取不再依赖原写入 Action 或生产者工具配置，不获得写入 lease／确认，也不重做写入或导出。
- `artifact_read`、列表、版本列表同样走交付读取边界；列表／版本列表保留各自枚举权限，每个条目还需准确成果版本的阅读权限。原始运行和普通历史仍采用原执行授权。
- 保留生产工具及 `artifact_read` 的当前 Tools 偏好，严格比较保存的成果／导出元数据；正文页通过 Knowledge 验证不可变内容并重建原分页。依赖来源仍递归核对当前授权，缺失来源、循环、内容变化及私有附件均不能通过交付绕过。
- 新增 `POST /agent/delegations/{delegationID}/delivery-result`，仅读取指定交付／验收中明确列出的结果引用；整段 run 的 evidence 不代表释放其中所有调用。`delivery_revision=0` 读取当前交付，正数读取历史记录中的准确 revision。每页复核当前 `delivery_read`、引用 SHA256、原调用及其来源；拒绝未提交、变化、失败或结果不明的记录。
- 接口沿用 UTF-8 分页和完整结果哈希，响应不包含工具调用参数或执行上下文。原结果自身已有的源凭证内容按相应 owner 策略读取。Module、公开 SDK 和 SaaS 客户端／服务端分发均已接通；新能力是可选接口，旧服务缺失时明确返回不可用。
- 页面在当前完成条件和交付历史中提供“查看第 N 项原回执”，使用新接口。只有交付阅读权也能读取回执；查看执行过程仍要求执行阅读权。使用原有完整结果校验、取消、关闭清除及窗口切换清除；委派／权限变化后清除失效视图，历史请求取消后不能重新填回内容。

## 验收场景

1. 六种成果工具的应用层场景使用真实 Knowledge service 和有界存储夹具，覆盖写入权限撤回、空执行 profile、准确结果版本授权、两类工具偏好、枚举权限、来源撤回、跨 owner、元数据／正文／导出修改、循环与私有附件。
2. 真实 Identity／Tools／Knowledge／Agent／SQLite 的 HTTP worker 完成创建、修改、导出和读取；三次写入分别经过原操作确认，保存四份真实回执。撤回全部成果写权限和执行阅读权后，当前／历史交付及完整分页仍可读，逐页拼接哈希与原结果一致。未提交引用、错误版本、来源撤权、禁用工具、重启和恢复均检查。
3. 新分页入口另测两页之间撤权、当前与历史引用归属、缺少调用的来源快照、失败／不明结果和不支持独立读取的 owner。SaaS 真实 HTTP 转发保留主体、revision、引用和分页，传播 owner 拒绝并挡住跨 workspace 调用。
4. 报表／分析和真实邮件写入回执的既有 HTTP 场景也通过新入口读取已交付结果，继续检查没有新增操作效果。
5. 真实 Chrome 使用构建后的页面，在只有交付阅读权时展开当前和历史回执；来源阅读权撤回后移除已有内容，恢复后需重读；关闭、刷新和 390px 窄屏均通过。记录无页面异常、未请求普通执行结果端点。

命令、日志、截图及源码摘要见[本批证据](evidence/2026-09-13-c05-artifact-and-delivery-reading/commands.md)。HTTP Action 和 OpenAPI 清单新增一个只读端点，普通 HTTP 共 92 条、SaaS 共 115 条，相关完整清单断言已更新。无新增数据表或迁移。

## 保留待办

跨用户／角色执行主体、交付范围内的完整成果正文／下载入口、Knowledge 资料检索／抽取及业务等其余 owner 的独立成果阅读策略、明确资料共享入口继续属于 C05。已实现的完整结果读取指原工具结果；若原调用只保存元数据或正文的一页，不会据此自动放开整个成果或导出文件。当前读取权限仍依赖原 owner／workspace 范围；`share` 尚无共享操作流程。没有通过更换主体、自动复制附件或省略来源检查扩大范围。
