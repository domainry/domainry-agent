# C05：主体数据删除与协作清理

Agent 的主体数据删除入口现在同时清理协作关系。删除发起主体时，先停止接收方尚未结束的任务，再删除发起方数据；接收方自己的运行、原工具回执和无关私有会话保留。删除执行主体时，发起方委派保留 `subject_exited` 元数据，未结束工作取消，已验收交付的状态保持。读取入口不再访问已删除任务，也不返回约定、交付或执行正文。完整 C05 尚未验收，清单保持 4／25。

三种协作索引纳入原主体预览、导出和删除范围：执行主体绑定、委派参与人、共享 Agent 成员。仅移除当前 Runtime／工作区中准确主体的关系，其他成员及同用户其他工作区的数据保留。相关未消费消息标为失效，避免通知重新唤醒已退出工作；原消息文本保留审计用途。已声明依赖的后续工作收到变更并停止，原要求版本保持。

全部清理与原删除回执在同一事务内进行。遇到错误归属时回滚，包括已经尝试的对方任务取消；相同请求并发和重试返回相同持久回执。取消前已经开始的原工具可以记录迟到的真实结果，保持原运行取消状态；不能继续模型执行或开始新工作。

页面显示“执行主体已退出”，隐藏执行查看、恢复和重新发布操作，不再将退出记录计入“需要我处理”。桌面和 390 像素窄屏截图已逐张查看。
