# K07 上传结果待核查与恢复

2026-09-11。修正会话附件把未知上传结果显示为“处理失败”的问题。与 B04 的待核查约定对齐：已经尝试上传，但没有收到回执、也没有观察到远端处理完成时，持久保存 `needs_reconcile`。原文件、来源、文档编号、请求编号和写入标记保持不变。

## 代码边界

- [存储事务](../internal/infrastructure/persistence/database/agent/conversation_attachment_index_store.go)依据已保存的上传与观察标记分类，继续使用原租约和 ORM 事务；没有增加迁移或原件解析。读取失败、远端不可见及暂无错误码时都不能把未知结果变成确定失败。
- 公共 SDK 的附件状态说明补上 `needs_reconcile`；接口形状、鉴权、Connector 操作和请求身份不变。当前 Agent 不承诺未知上传可以重新提交，也没有新增清空写入标记的操作。
- [附件状态](../frontend/src/attachment-state.ts)和[附件窗口](../frontend/src/AttachmentDialog.tsx)显示“上传结果待核查”，继续刷新状态并允许按原权限预览、下载和另存原件。核对按钮仍依据后端当前能力开放。
- 已经观察到处理完成的附件，不会仅因原始上传回执丢失而再次被判为上传结果未知。删除中的附件也不会被迟到状态复活。

## 实际验证

[存储回归](../internal/infrastructure/persistence/database/agent/conversation_attachment_index_store_test.go)覆盖多次未知／不可见／查询失败、关闭重开数据库、同一请求核对、拒绝重传、正向观察恢复和删除关系。未知状态全过程保留同一原件引用及来源；观察恢复不伪造 `put_acknowledged`。专项与 race 均通过。

[网页场景](../frontend/tests/attachment-unconfirmed.browser.mjs)运行当前构建产物，使用实际 Identity、Module HTTP、SQLite 与官方 Connector 的隔离协议夹具。远端模拟收到一次原件后丢失回执，随后持续返回不可见，直到场景显式恢复可见。

| 实际步骤 | 结果 |
| --- | --- |
| 私有上传后显式提交检索；远端响应丢失 | 显示待核查，禁止再次开始上传 |
| 远端两次不可见核查，期间完整重启宿主并重放原启动请求 | 原附件、原内容哈希保持一致，上传仍为 1 次 |
| 结果未知时预览 PDF、下载原件 | 实际画布完成渲染，下载与原件字节完全一致 |
| Identity 撤销核对权限、直接请求、恢复权限 | 按钮禁用，直接请求 403；恢复后可核对 |
| 桌面与手机展示 | 两项机器基线通过，已查看截图；无横向溢出或控件重叠 |
| 远端恢复可见 | 同一附件进入 ready，没有新增上传 |
| 删除附件 | 原件接口 404，远端删除 1 次，持久状态及物理原件清理核实 |

最终整段网页验收 **11.98 秒通过**，宿主审计确认 `hidden_fetches=2`、`remote_puts=1`、`remote_deletes=1`、`put_acknowledged=false`、`index_observed=true`，原件已清理且没有解析缓存。Agent / SDK 全量 Go 测试、相关 race / vet、前端 42 项测试和构建均通过。

首次网页运行 3.99 秒失败：测试脚本的直接 GET 漏带 `X-Agent-Scope`，实际接口正确拒绝为 409。修正脚本并在核对前读取最新界面版本后，第二次整段通过。失败报告与截图保留。本批没有重复真实 Verdent 调用；先前实际私有附件链路见[真实附件验收](testing-2026-09-11-private-attachment-live.md)，本批特意验证无法观察结果的故障窗口。

[机器证据及 18 个文件的 SHA-256](evidence/2026-09-11-k07-attachment-unconfirmed.json)包含成功／失败记录、宿主审计、桌面／手机截图及字节一致的原件与下载文件。

## K07 的范围确认

B04 明确约定“无法确认时进入待核查状态”，这一行为已完成上述验证。此前 K07 增量又把完整上传回执契约列为剩余项；若要求未知结果也可以明确取消或重新上传，需要扩展并发布知识服务，不能仅凭当前受权限过滤的查询推断操作未发生。已向用户确认是否扩展该范围，K07 暂不勾选；本批不把新的状态显示等同于新增了上游回执接口。
