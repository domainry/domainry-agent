## 设计约定

- Agent 具有独立身份和生命周期，角色平等；Agent、任务、委派和消息分别建模。一个 Agent 可以处理多个隔离任务，也可以向其他 Agent 发出委派。
- 委派记录发起方与接收方，关系可以形成协作网络。管理权限定在具体委派；取消一项委派不销毁接收方 Agent，也不影响其其他任务。原任务的来源关联继续用于追溯，不赋予 Agent 父子关系。
- 角色平等不代表数据权限相同。执行使用当前用户／服务主体授权、接收方能力与本次委派范围；发起方不必配置接收方全部专业工具，但必须有委派相应工作的权限。
- Agent 拥有协作、任务状态和执行记录，公共契约归 Agent SDK；工具声明与适配沿用 Tools，身份归 Identity，资料与成果归 Knowledge，连接归 Integration／Connectors，时钟与通知分别归 Scheduler／Notification。
- 第一批按现有部署边界实现，复用执行账本和 worker。跨独立 Agent 服务的通信协议在明确部署需求后扩展。

## P0：Agent 协作与委派，先交付完整页面链路

- [ ] C01 **独立 Agent 与目录**：区分能力定义和可接收工作的 Agent 实例，提供稳定身份、名称、能力摘要、配置版本、启停与可接收状态；支持发现和选择获准使用的 Agent。
- [ ] C02 **按 Agent 执行任务**：任务绑定接收方 Agent，每个任务保持独立上下文；冻结配置版本、模型标识和工具范围，恢复时核对版本与当前授权。扩展现有任务实现，保留已有会话和计划入口。
- [ ] C03 **双向消息与运行中补充**：建立持久收件箱，标记发送者、接收者、任务／委派和消息类型；支持下一步补充、下一轮排队、问题与回复。记录送达和消费状态并去重；Agent 消息保留真实身份，不能冒充用户授权。
- [ ] C04 **委派生命周期与管理**：支持发起、受理／拒绝、等待补充、执行、交付、验收／补充工作，以及暂停、取消、恢复和失败处理。保存目标、输入、交付要求、预算与版本；变更要求需明确接收，转交需关闭或核实旧执行，避免重复效果。
- [ ] C05 **委派授权与资料共享**：分别定义发起、接收、管理、沟通、查看执行和读取交付物的权限；专业工具执行权与成果查看权分开。跨任务资料通过受权引用或明确共享提供，继续核对来源权限与私有附件范围。
- [ ] C06 **协作页面与实时详情**：主会话展示委派 Agent、任务、实时状态、当前步骤和等待事项；提供“我发出的／我接收的”列表。点开复用运行详情，查看公开进度、双方通信、工具参数／结果、错误、成果、引用和用量；可发消息及管理具体委派，刷新重连后恢复现场。
- [ ] C07 **异步交付与协作恢复**：委派立即返回稳定 ID；等待释放 worker，消息／交付事件唤醒任务。持久保存委派、投递、交付和验收记录，支持重启、重投去重、停止与回执竞态；限制同一工作目标的委派数量、总预算和通信频率，检测循环等待。转委派需明确策略和来源链路。

第一批完成标准：用户交给 A 一项工作 → A 分别委派给 B、C → 页面同时显示 B、C 的真实执行 → 用户或 Agent 补充要求 → B、C 交付 → A 验收并汇总。期间刷新、重启或取消其中一项，状态与已完成效果仍可核实；不要求一次性实现所有高级规划能力。

## P1：通用自主推进与执行效率

- [ ] E01 **持久目标与持续推进**：在现有任务目标和计划跟进上补通用 Goal 生命周期、阶段进度、未完成事项和跨轮继续机制；明确暂停、阻塞、完成及预算耗尽的处理，沿用既有后台任务与调度入口。
- [ ] E02 **计划与动态调整**：持久保存步骤、依赖、输入输出、执行者和状态；根据新消息、工具结果与失败调整后续步骤，保留已完成证据和计划版本。简单请求可直接执行；规划指导与实际执行授权分别处理。
- [ ] E03 **完成验收与恢复决策**：把每项交付要求关联到工具回执、数据或成果版本；区分受理、执行结束、交付和验收通过。可确定验证的条件由程序检查，其他条件记录模型评估或用户决定；遗漏则续办，外部结果不明则先核查，不能仅凭 stop 标记目标完成。
- [ ] E04 **受控工具并行**：先支持无依赖且明确声明可并行的读取调用，再按资源冲突规则扩展；保留调用前授权、结果有序归档、取消收敛和独立回执。多个 worker 与单任务工具并行分别计量。
- [ ] E05 **跨 Agent 预算与进度诊断**：复用当前用户／工作区容量治理，增加任务与委派汇总的模型用量、调用、耗时和预算分配；转委派不能重置预算。识别重复调用、反复修订和无进展循环，选择调整策略、等待或报告具体阻塞。
- [ ] E06 **长上下文管理**：在现有字节上限、摘要和结果按需读取上补模型上下文压力估计、执行中区间压缩与可恢复的溢出处理；保留任务要求、用户修正、待办事项、工具调用配对和来源复核。
