## 长期会话与日常体验验收（同日第二批）

### 真实长会话

`TestGatewayLiveLongConversation` 使用真实 Gateway `glm-5.3-flash-free`、默认 65,536 字节上下文预算、独立临时 SQLite 数据库，所有原始消息均经 ConversationService.Send 写入。

最终运行结果：17 次真实回复、11 次真实摘要、34 条原始消息；传入模型的序列化消息数组最大 42,156 字节；摘要覆盖至第 22 条原始消息。校验项目代号 CEDAR-928、用户将周五纠正为周四、仍未完成的核对发票、先做网页版本的决定。关闭旧服务实例、关闭并重新打开 SQLite 后，新的服务实例读取持久摘要继续回答，模型请求不重复注入已压缩原文。原始历史通过 30 条最新页加 4 条早期页完整读回。耗时 129.51 秒。

真实调用暴露了摘要 JSON 带 Markdown 代码块的兼容问题，现已修复；单个完整 JSON 代码块可接受，其他语言、外围说明、多个块、未知字段、错误类型、尾随 JSON 和空摘要仍会失败。摘要提示进一步要求保留仍有效事实与未完成事项，显式采用用户最新纠正。本次是有限验收用例，不代表模型摘要不会在其他输入上遗漏信息。

历史日志保存在当时的本机验收目录中。API Key 仅临时注入测试子进程。正常 CI 不执行真实模型验收。
