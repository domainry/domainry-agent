# K06：移除后端原件解析，接入原文件在线预览

2026-09-11。用户明确要求检索由 Connector 提供，Agent 根据检索结果打开原文件；源文件解析不做，已有实现删除。删除、升级清理和原件在线预览均已验收，K06 已勾选。先前批次记录见[证据索引](evidence/2026-09-11-k06-original-preview.json)，剩余项复验与完成依据见[完成证据](evidence/2026-09-11-k06-original-preview-complete.json)。

## 已删除与保留的边界

- 删除 Agent SDK 的原文件解析器 / 解析任务 / 产物存储接口；删除 Go XLSX / CSV / TSV 解析实现与 Excelize 依赖、解析应用服务、私有 JSON 缓存、后台租约 worker、默认注入和本地正文分页。
- 删除私有附件读取 / 提取模型工具及 `parse_supported` 提示。附件继续私有保存，可预览、下载或另存资料库。
- Connector 检索 / fetch 保留。`knowledge_extract` 只处理 Connector 返回的内容，不打开原文件，不作为预览前置条件。
- SDK 只保留被动的旧工具定义快照用于验证历史远端回执，不进入当前工具目录或执行入口。原本依赖本地解析的旧来源在历史与工具结果复用前明确拒绝；原始对话记录没有破坏性重写。
- 第 12 个历史迁移保持原校验和；第 13 个宿主迁移通过 ORM 清空废弃任务元数据。空的历史表没有运行时读写。Web 宿主移除以前自管的 `.parses` 缓存目录，保留 `.documents` 和 `.attachments` 原文件。

## 在线预览实现

`KnowledgeSources.tsx` 根据已经由应用层映射的本地资料库 / 文档 ID 打开原件。`FilePreviewDialog.tsx` 统一管理资料库、检索引用与附件入口；`file-preview-state.ts` 只接受已知本地资源 ID，不请求引用里的任意 URL。

一次原件请求返回文件字节、权威文件名、长度和 SHA-256；前端校验长度 / 哈希与身份范围。接口继续调用现有受权下载操作，不增加文件读取端口或前端权限预检请求。重新打开 / 下载重新授权，关闭后销毁查看器和 worker；切回页面重新读取，不持久保存浏览器文件副本。

查看器按需加载：

- [PDF.js](https://mozilla.github.io/pdf.js/examples/index.html) 6.3.289：在浏览器渲染原 PDF 页面、翻页与缩放。worker、CMap、字体和 WASM 资产随产品构建提供。
- [docx-preview](https://github.com/VolodymyrBaydalka/docxjs) 0.4.0：Word 段落、排版和表格，在无脚本沙箱 iframe 中展示；禁用 HTML AltChunk，CSP 限制外部资源。
- [ExcelJS](https://github.com/exceljs/exceljs) 4.4.0 与 numfmt 3.2.6：只在浏览器读取工作簿，显示工作表、合并单元格、基本样式和保存的公式结果；不执行公式。行 / 列分窗展示，支持跳到实际单元格。

Office 文件在可终止的浏览器 worker 中做解压边界检查；原件沿用 16 MiB 上传上限，实际展开 32 MiB、4096 条 ZIP 项，20 秒 worker 期限。Excel 最多 64 个工作表、每表 10 万行 / 4096 列、合计 25 万个非空单元格。超限明确提示下载。它们是显示原文件的前端组件，没有服务端解析 / 正文缓存 / 索引或模型调用。

## 支持范围

对只返回检索片段、没有本地原件的外部来源，仅保留来源链接，不能从片段伪造 PDF / Office 原件。旧 .doc / .xls、加密文件、复杂 Office 图表 / 嵌入对象不宣称完整支持；使用界面中明确的原件下载入口。上述限制不引入后端解析或转换任务。
