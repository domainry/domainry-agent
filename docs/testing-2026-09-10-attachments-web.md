# 会话附件原文件、接口与网页验证

日期：2026-09-10。此次完成会话私有附件的本地管理链路，未交付远端私有索引、共享资料库成员管理或知识提取；K04 / K05 / K07 保持未完成。

## 实现与边界

- SDK 增加可选 `ConversationAttachmentService`、私有 Storage 和当前权限 Authorizer。Module 与 SaaS 共用应用服务，浏览器传原始二进制，可信 RPC 使用有界 base64。单文件 16 MiB；SaaS 仅附件上传 / 下载放宽至 24 MiB 的编码载荷，其余接口保持原限制。
- Web 宿主使用数据库旁的 `.attachments` 私有目录，目录 0700、文件 0600；按 Runtime / Workspace / User 隔离，文件名不作为存储路径。读取验证大小和 SHA-256。每个对象的操作使用 OS 文件锁，持久删除标记阻止晚到上传重新创建原文件。
- 上传先预留元数据，再持久保存文件，最后按修订更新为 stored。相同请求重试复用记录；不同文件内容不能占用同一请求标识。原文件不进入消息正文，也不自动推送远端知识库。
- 第 8 个宿主迁移增加 `_agent_attachment_cleanup`。撤销访问、记录清理任务位于同一事务；删除会话也会登记附件清理。宿主关闭重开后工作进程继续处理，失败延后重试。远端 Source 非空时尚无可验证的删除适配器，会保留任务与引用，不假报清理成功。
- 五个接口：会话内附件上传、列表、详情、原文件下载、删除。分别注册 `agent.conversations.attachments_*` Identity 权限，默认不自动授予；应用服务还验证所有者和来源会话。自定义 Module / SaaS 宿主需注入 Storage 和 Authorizer；未配置时明确不可用。独立 Web 宿主已默认装配。
- 网页增加会话标题旁的“附件”入口，支持选文件、状态、文本预览、下载请求及具体文件删除确认。浏览器仅保存上传重试的标识 / 名称 / 大小 / 摘要，不保存原文件字节；刷新后需重新选择同一文件才能重试。该重试 UI 尚未完成断网 / 刷新专项验收。
- 文本预览只解码 UTF-8，以普通文本显示，最多 65,536 个字符；PDF / Office 目前仅支持原文件下载，解析预览未接通。stored 明确显示“已保存 · 未入库”，不声称助手能检索或提取内容。
