# C05：业务原分页的 NULL 否定与 deny 范围

接续[报表排除与 NULL 范围](testing-2026-09-14-c05-report-negation-scope.md)。业务原回执范围证明原本支持“非空范围覆盖比较命中的行”，但在否定内部和 deny 策略比较时也复用了这一规则。NULL 上比较的 SQL 结果为 UNKNOWN，非空检查为 FALSE；两者不满足可反转的真值顺序。因此当前读者已经通过 SQL 隐藏 NULL 时，旧证明仍可能允许原分页中包含隐藏 NULL 的总数／游标。

本次在显式 NOT、原生不等／排除的反转证明及 deny 范围中递归要求 SQL FALSE ≤ UNKNOWN ≤ TRUE 顺序。AND／OR 子分支保持此要求；普通正向的命中行包含仍可使用非空覆盖比较，前缀、有限集合与当前绑定身份的既有规则保留。实际权限与原提供者证明没有被模型参数替换。

四个真实 SQLite ORM 反例分别使用显式 NOT、原生不等、显式否定 deny 组合和原生不等 deny 组合。原查询首行 Alpha 可读，原总数 2 和游标还包含 NULL；读者真实查询与首行读取均成功，但 SQL 不返回该 NULL 行。旧代码 Go overlay 对照四项全部放行原总数，故测试失败；当前代码四项拒绝，恢复完整读者范围后原页又可读取，原证据字节不变。
