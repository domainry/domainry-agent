## 解析的用途

解析把原件转换为带结构和位置的可处理内容，目的是支持用户的具体任务。问答需要检索相关片段；精确字段或明细提取可以在服务端执行规则；数字汇总应使用结构化计算。不能把“大文件拆页，然后模型从头读完”作为默认工作方式。

当前代码已经支持指定原件的读取和服务端字段 / 表格提取。本地解析结果尚未写入 Verdent 搜索索引，也没有因此完成 `analysis_run`。分页是补充读取入口，不等于检索或分析已经实现。

## 当前实现

- SDK `conversation_document_read.go` 定义不含正文的 `ParsedDocumentReference`、有界 `DocumentReadPage`，以及 `knowledge_read` v4。现有原件读取和解析存储端口不变；应用层不导入存储或格式解析实现。
- [应用投影](../internal/application/knowledge_document_projection.go)先经过已有源端口读取当前受权原件，再从私有解析缓存的内容生成少量正文。单个片段最多 2048 UTF-8 字节，单次来源结果最多 7680 字节，给既有 8 KiB 工具预览留出信封空间。`limit` 是片段上限，默认 20、最多 50；实际还受字节预算限制。
- 长行或长单元格按真实字节边界续读，携带 block ID、工作表 / 行、offset / end / total_bytes，不伪造文件页码。游标绑定来源范围与版本摘要和位置；不是授权凭据。每次继续读取仍检查当前原件和权限。`complete` 仅表示遍历完已解析的正文块，不表示完整恢复了原文件版式、公式或所有特性。
- `knowledge_extract` v3 在服务端对所有可用的解析块执行已明确的规则，无需模型把每一页先读完。结果保留提取值、引用及实际单元格位置；`Source.Data` 仅保存原件 SHA、解析器身份、解析产物 SHA、文档 / 会话标识、格式、覆盖说明和数量等元数据，不包含正文块。真实 XLSX 此字段为 **646 字节**。
- 历史复用先重新读取当前获准的原件及缓存，核对来源引用，再重算提取结果。篡改产物哈希、解析器版本、会话范围或正文页均拒绝。缓存仍不是授权。旧 v2 提取的完整来源回执继续可验证，当前 v3 拒绝用旧全文结构替代精简引用；既有历史记录不被重写。
- 远端知识源仍使用原契约；不支持分页的远端源收到分页参数会明确失败。本轮精简的是我们自己保存、解析的原件，不宣称已消除所有远端来源正文副本。

## 验收范围

1. [有界投影单元测试](../internal/application/knowledge_document_projection_test.go)：80 个正文块、中文和 emoji、超过单页大小的长单元格；多页重组与原文逐字节一致，不丢失或重复内容，每页与每片段均在预算内；错误 UTF-8 位置、不同来源范围的游标以及远端不支持的分页被拒绝。
2. 同文件测试验证精简来源不含正文，篡改解析哈希 / 版本 / 会话范围 / 全文替换和正文页被拒绝；真实旧 v2 来源表示仍可复核。
3. [实际私有存储集成测试](../integration/conversation_document_projection_integration_test.go)：约 40 KiB 的合成 CSV，共 82 行，目标位于 B82。模型只调用一次 `knowledge_read`，首个返回页没有目标值，然后调用 `knowledge_extract`，服务端返回 `12345` 及 B82 来源。整个流程只实际解析一次；历史回复可以通过精简来源重新授权。
4. 既有私有附件及资料库原件集成测试继续覆盖冻结输入重启、跨会话 / 用户 / 工作区、历史原文和旧工具结果的隔离、撤权与恢复、解析中撤权和删除。
5. 真实 `glm-5.3-flash-free` 验收 **47.77 秒通过**：模型发现附件、按实际正文选择规则，四个字段、缺失邮箱、两行明细及实际单元格正确；复核原件 SHA、完整解析产物 SHA 与精简来源一致，重启、权限撤销 / 恢复、附件与缓存删除通过。未配置知识服务，不上传远端 KB。
6. 网页使用既有构建的产品客户端，协议夹具驱动模型决策；真实解析、Identity、HTTP、SQLite 与缓存。验证上传、原件下载、桌面 / 手机字段与表格、引用、重启、撤权 / 恢复、删除。此轮未改变产品前端组件，因此不重复前端构建或状态单测。

网页复验宿主 38.89 秒通过；四个布局基线无质量错误或页面溢出，浏览器异常为 0，人工检查手机结果和桌面来源通过。Agent / SDK 全量、相关 race 与 vet 均通过。完整测试命令、最终状态、网页截图和失败记录见机器索引。

## 失败与修正

- 首轮大原件用例未通过，最初单页上限 32 KiB，与既有 8 KiB 工具结果预览预算不匹配。收紧来源页至 7680 字节并增加模型夹具错误输出，最终用例通过。首轮没有保留更细的模型错误，不能把预算差异当作已证实的唯一原因。
- 网页首轮在流式回复消失、持久消息页尚未加载完成的间隙立即断言正文，得到仅包含用户消息的快照。改为等待已持久化回复中的全部预期字段和明细；保留完整内容、引用、权限和删除断言。失败时的自有合成附件已删除，原服务已正常结束后再启动复验，未因观察超时重启活跃任务。

## 尚未完成

DOCX / PDF 本地解析仍待实现，现有资料库的这两类格式继续使用远端解析内容。局部内容检索、把本地单元格写入知识索引、表格计算以及更大文件的隔离处理不能由本轮分页或引用代替。当前仍遵守既有 16 MiB 输入、512 KiB 解析输出等边界，超限明确失败。
